# v0.4.10 Plan — Output Contracts, Determinism & pysnmp Deprecation

**Theme:** close out the review program: honest output contracts, byte-deterministic
sidecars, and the formally-decided deprecation of the pysnmp `.py` format.

**Status:** shipped 2026-09-22

## Review residue (from the v0.4.9 implementation review)

Resolver/reader/formatter items surfaced by the independent review of v0.4.9; fold into this release's scope:

| Item | Notes |
|------|-------|
| Offline fallback on fetch failure | On a failed source fetch, fall back to a fingerprint-less `cache.get(name)` with a "serving cached N; source unavailable" warning — restores offline/air-gapped workflows without weakening freshness when the source is reachable (v0.4.9 took that workflow away with fetch-first fingerprinting). |
| Alias skip-path silent discard | The resolver's fetch-result-loop skip guard discards a genuine fetched file's content when its declared name was already claimed by an earlier file in the wave — no collision warning, first-wins (the parse path warns and is last-wins). Route the skip path through the same `_record_module` collision-warning treatment. |
| Aggregate nested-zip cap escalation | Budget exhaustion raises `MibSizeLimitError` for the whole run; a legitimate bundle of many small nested zips can trip the 4× heuristic — treat as a recoverable miss (skip that archive) or make the multiplier configurable. |
| `set_artifact_metadata` dead API | Zero call sites since the per-run formatter refactor — delete it or document the construction-time metadata contract (exact-type rebuild also silently stale-dates hypothetical `JsonFormatter` subclasses). |

## Non-goals

- pysnmp `.py` **removal** — deferred to the next minor release (breaking change; see
  outlook below).
- New features.

## Acceptance criteria

- `--format pysnmp` emits `DeprecationWarning` + CLI notice; output still produced (test).
- `--reproducible` produces byte-identical `manifest.json` across runs (test), or the
  determinism claim is removed from `json_bundle.py`.
- Compatibility policy documented and covered by a contract test against a pinned
  trishul-snmp consumer version (per #16).
- Every remaining #23 item is either fixed or its claim deleted.
- Release gate per `docs/release-checklist.md`.

## Outlook — v0.5.0 (minor bump, reserved for major change)

Per maintainer direction, the 0.4.x series stays patch-level; the minor bump is reserved
for major/breaking scope:

- **pysnmp `.py` format removal** (breaking; follow-up to #24 deprecation).
- **Offline-fallback staleness edge case** (v0.4.10 review M1): a cached misnamed alias
  served offline can beat a genuinely fetchable source in the same wave — prefer the
  fresh fetch on the skip path when the claiming entry was fallback-served.
- Feature backlog from `docs/roadmap.md`: MIB lint mode (`tsmi lint`), watch mode,
  plugin system for custom formatters, MIB borrowing (pre-compiled fallback registry).
